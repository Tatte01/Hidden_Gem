# Artefact 01 Project Requirements & Initial Dev Plan

## Project: Hidden Gem

Hidden Gem is a mobile application designed for users to share, store, and discover their favorite locations. Users can create personal recommendations for spots they've visited and share those "hidden gems" directly with their friends on the app.

### Key Features to be Implemented:

- User Authentication: Login via Google or Facebook.

- Interactive Map: Browse locations using an integrated Google Maps interface.

- Location Management: Add, view, edit, and delete (CRUD) location recommendations.

- User Profiles: Create and edit a personal profile page.

- Social Connectivity: Add and manage friends within the app.

## User Personas

### User Persona 1: Chloe
Name: Chloe
Age: 25
Occupation: Student
Education: Bachelor of Science in Psychology
Technical Proficiency: Average
Bio:
Chloe is a graduate student who enjoys exploring local coffee shops and boutiques.
She uses the Hidden Gem app primarily as a social tool to share her favorite urban discoveries with her close circle of friends and family.

Key Needs & Requirements:
To easily share general locations of coffee shops and stores with friends.
The app should be social, intuitive, and visually appealing.
Precision is less critical than a good description and atmosphere of the location.
She values the ability to write recommendations and see her friends' recommendations.

### User Persona 2: Bob
Name: Bob
Age: 55
Occupation: Idustrial worker
Education: No formal higher education
Technical Proficiency: Low
Bio:
Bob is an experienced outdoorsman and a Idustrial worker.
He uses the Hidden Gem app with his hunting team to mark and navigate to specific,
remote locations in the woods. He has little patience for complex apps.

Key Needs & Requirements:
Extremely accurate GPS coordinates are essential for navigating to remote areas.
The interface must be simple, straightforward, and easy to navigate.
No unnecessary features or complex menus—just core functionality for dropping and finding pins.

## Software Requirements

### 2.1 Functional Requirements

#### The system shall enable users to:
- User Account Management: Register a new account and login into an existing account.
- Gem Management: Create and place new gem markers on the map.
- Social Connectivity: Add other users as friends.
- Profile Management: View and edit their own user profile information.

### 2.2 Non-functional Requirements
- Performance: Application page transitions, particularly between the login/register and home pages,
    must be fluid and instantaneous with no perceivable lag.
- Usability: The user interface must be professional, intuitive, and easy to navigate.
    Text and elements on the profile page must be clearly legible and well-organized.
- Reliability: User actions (adding a gem, adding a friend, editing a profile) must be processed reliably with clear feedback confirming success or failure.
